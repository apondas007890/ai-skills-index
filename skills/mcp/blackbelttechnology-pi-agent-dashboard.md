# Pi Agent Dashboard

## Description

Real-time web dashboard for pi coding-agent sessions. Multi-session view, live chat mirroring, integrated terminal, diff viewer, pi-flows execution, and mobile-first remote control via mDNS or zrok tunnel. Coexists with pi's TUI — doesn't replace it.

## What it does

Provides Model Context Protocol (MCP) server integrations or external tool connectors for AI agents. Focused on `agent`, `agent-framework`, `agent-orchestration`, `agent-skills` and designed to work with claude-code, codex, cursor, gemini-cli.
