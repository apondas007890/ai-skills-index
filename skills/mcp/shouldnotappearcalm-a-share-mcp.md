# A Share Mcp

## Description

基于 MCP（Model Context Protocol）协议的 A 股股票数据服务，零配置开箱即用，完全免费无需注册。提供沪深市场实时行情与历史数据，包括分时、分钟线、日线 K 线及常用技术指标，内置新浪与腾讯双数据源并支持自动故障切换。统一以 DataFrame 格式输出，适用于量化研究、回测分析及自动化交易系统开发。
