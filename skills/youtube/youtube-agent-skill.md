# YouTube Agent Skill

## Description

A collection of `SKILL.md` modules (`yt-script` and `yt-package`) built to assist YouTube workflows with hook formulas, `title/thumbnail` pairing lints, and structured video script generation.

## What it does

Guides AI agents through packaging a YouTube video (evaluating title and thumbnail alignment) and drafting retention-focused scripts with proven hook patterns.

## Best for

- Structuring YouTube video hooks and retention scripts
- Checking `title` and `thumbnail` concept alignment before filming
- Building repeatable YouTube content pipelines with AI agents
