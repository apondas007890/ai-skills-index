Exposes `SpicyAPI` model listing, cost quoting, and generation endpoints to coding assistants via `MCP` tools and skill instructions (`Wayfinity/spicyapi-skills`).

## Best for

- Developers explicitly building 18+ / adult-oriented `SpicyAPI` integrations
