# Agentic Awesome Skills (AAS)

## Description

A massive catalog of 3,000+ reusable AI agent skills paired with AAS Core for local catalog discovery, agent-owned selection, and plan previews across Claude Code, Codex, Cursor, and Gemini CLI.

## What it does

Packages thousands of `SKILL.md` playbooks alongside a CLI, MCP server, and plugin layer so agents can search, preview, and load capabilities on demand.

## Best for

- Finding ready-to-use `SKILL.md` playbooks across niche engineering and workflow domains
- Running local skill catalog discovery with plan previews before execution

## Verdict

EXCELLENT — one of the largest and most actively maintained skill catalogs on GitHub (50k+ stars, MIT license).

## Limitations

- Because it aggregates 3,000+ community playbooks, individual skills vary in depth and should be inspected before running.

## Risk

Inspect individual skills and any bundled scripts with `NVIDIA/SkillSpector` before enabling them in production workspaces.

## Installation

See the GitHub repository (`sickn33/agentic-awesome-skills`) for CLI, MCP, and plugin setup instructions.

## Notes

Great upstream source for discovering specialized skills to evaluate in SkillAtlas.
