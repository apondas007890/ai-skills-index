# VoltAgent Awesome Agent Skills

## Description

A large, actively curated directory of 1,000+ open-source and official AI agent skills (`SKILL.md`) across coding, DevOps, research, and design workflows.

## What it does

Indexes community and vendor-maintained skills with direct links, categories, and compatibility notes for Claude Code, Codex, Cursor, and Gemini CLI.

## Best for

- Discovering new candidate skills across specialized domains
- Benchmarking how official teams structure `SKILL.md` repositories
- Feeding new links into this library's `inbox/` evaluation pipeline

## Verdict

EXCELLENT — one of the best starting points on GitHub for discovering high-signal agent skills.

## Limitations

- Directory index only; individual linked skills still require independent security and quality inspection (e.g. with `NVIDIA/SkillSpector`).

## Risk

Review each linked third-party skill individually before installing.

## Installation

Browse `VoltAgent/awesome-agent-skills` on GitHub and evaluate individual skills before installing.
