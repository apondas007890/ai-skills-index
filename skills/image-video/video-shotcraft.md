# Video Shotcraft

## Description

An AI video skill for Claude Code and Codex that turns product pages or specs into editable, cinematic promotional videos built with `Remotion`.

## What it does

Ships 150+ reusable shot recipe cards, motion previews, beat synchronization, sound design hooks, and automated storyboarding to render crisp React/Remotion video frames without generative video artifacts.

## Best for

- Product launch demos, SaaS promo videos, and UI showcase reels
- Clean, editable `Remotion` motion graphics driven by coding agents
- Beat-synced promotional edits with deterministic text rendering

## Verdict

GOOD — practical `Remotion`-based video skill with 150+ shot recipes and crisp typography/UI rendering.

## Limitations

- Focuses on code-driven `Remotion` compositions rather than photorealistic AI video.
- Repository summary reviewed; not personally rendered locally.

## Risk

Apache-2.0 licensed; inspect `Remotion` dependencies and media assets before building.

## Installation

See `Vincentwei1021/video-shotcraft` on GitHub for skill and `Remotion` setup.

## Notes

Complements `hyperframes` if you prefer React + `Remotion` over raw HTML/FFmpeg compositions.
