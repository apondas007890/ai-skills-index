# RuiC Motion Reel

## Description

一句话 brief 生成动态图形 / 动效宣传片 · Agent Skill。时长按 BPM×小节算（12–60 秒），默认 1920×1080；常规宣传片走 remotion/ 模板，特殊质感走自研引擎：2× 超采样矢量/文字、真 3D 点云、丝网印四色分色、普朗克/薄膜干涉物理配色、代码合成配乐，不用外部美术素材、不用 AE。16 张风格牌为参考库，已做过九种视觉语言（暗色科技 / riso / 纸艺 / 银盐 / 普朗克恒星 / 氰版蓝图 / 紫外光刻 / 品牌暗色 / 品牌亮色），成片见 docs/films/

## What it does

Provides programmatic video editing, motion graphics, storyboarding, or visual media generation. Focused on `agent-skill`, `creative-coding`, `ffmpeg`, `motion-graphics` and designed to work with claude-code, codex, cursor, gemini-cli.
